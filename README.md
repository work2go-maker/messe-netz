# Fi Europe Messe-Netz (ATMSALT)

Öffentliche Messe-App für Aussteller der Fi Europe 2026 (Messe Frankfurt, 17.–19.11.2026):
3D-Hallenplan, Firmenprofile (aus dem offiziellen Ausstellerverzeichnis), Beitreten mit einem Klick,
Vorschläge „Wer passt zu mir?“, Chat für alle mit automatischer Übersetzung (MyMemory, kostenlos).

- `index.html` – die App
- `firmen.json` – Firmenprofile (Quelle je Firma: exhibitors.figlobal.com)
- `config.js` – Supabase-Adresse + öffentlicher Schlüssel (leer = Chat aus)
- `setup.sql` – Tabellen für Supabase
